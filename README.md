# 🐉 Kali Linux Cybersecurity Lab

> A practical cybersecurity lab built with **Kali Linux + Oracle VirtualBox + NAT Network**.

This repository documents the setup of a Kali Linux virtual lab using Oracle VirtualBox. The environment provides an isolated and reproducible platform for learning **cybersecurity, networking, penetration testing, and security tools**.

---

## 📌 Lab Overview

The lab consists of a Kali Linux virtual machine connected to a dedicated VirtualBox **NAT Network**.

### ⚙️ Environment

| Component       | Configuration     |
| --------------- | ----------------- |
| 🖥️ Hypervisor   | Oracle VirtualBox |
| 🐉 OS           | Kali Linux 2026.2 |
| 💻 Architecture | x64               |
| 🌐 Network Mode | NAT Network       |
| 🔌 Network Name | `Lab-Network`     |
| 📡 Network      | `10.0.0.0/24`     |
| 🚪 Gateway      | `10.0.0.1`        |
| 📦 DHCP         | Enabled           |
| 🖥️ Kali IP      | `10.0.0.3`        |
| 🧠 Memory       | 2048 MB           |
| ⚙️ CPU          | 2 Cores           |
| 💾 Storage      | ~80 GB            |
